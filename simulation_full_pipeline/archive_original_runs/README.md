# Archive of the original runs

These files are the **unmodified records of the original runs**. They are kept as evidence of the work. Some of their text is in Spanish because they were produced before the English translation of the code (19 November 2026). The English versions of the same files are in the parent folder, `simulation_full_pipeline/`, and are the ones to read and run.

| File | What it is |
|---|---|
| `Cuaderno6_simulacion_pipeline_completo.ipynb` | Original Spanish Notebook 6, as executed on 14 November 2026 (code cells with saved outputs). English version: `../Notebook6_full_pipeline_simulation.ipynb`. |
| `fullsim.py`, `fullsim2.py`, `run_sim7.py`, `analizar7.py` | Original scripts with Spanish comments and printed messages. English versions: same names in the parent folder. After removing comments, docstrings and printed text, the code is structurally identical. |
| `sim6_huellas.json` | Original fingerprints (first 16 hex characters of SHA-256) of the Notebook 6 output files, including the Spanish `fullsim.py`. |
| `Notebook7_executed_colab_2026-11-19.ipynb` | The researcher's reproduction of Simulation 7 in Google Colab on 19 November 2026 (2 h 47 min), with saved outputs. Its printed headings are in Spanish because it ran the original Spanish scripts. Result: 5 of 6 output files identical; the exploratory ceiling-contrast file differs slightly (see the main README). English notebook: `../Notebook7_reproduce_simulation7.ipynb`. |
