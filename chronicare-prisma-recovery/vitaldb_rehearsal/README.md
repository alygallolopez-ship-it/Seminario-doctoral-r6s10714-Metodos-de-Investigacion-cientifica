# VitalDB rehearsal notebooks (01 to 05)

Five Google Colab notebooks that rehearse the protocol on the open VitalDB dataset. Recovery is simulated; no real health outcome is analysed. Raw data are not stored here: the notebooks download them from the VitalDB API (CC BY 4.0).

| Notebook | CSV tables (folder `outputs/`) |
|---|---|
| `01_feasibility.ipynb` | `conteo_por_prueba.csv`, `conteo_por_ventana.csv` |
| `02_null_simulation.ipynb` | `simulacion_nula_vitaldb.csv`, `simulacion_nula_control_n20000.csv` |
| `03_noise_and_methods.ipynb` | `sim3_comparacion_metodos.csv`, `sim3_control_n20000.csv` |
| `04_coupling_and_power.ipynb` | `sim4_poder_por_n.csv` |
| `05_mean_level_test.ipynb` | `sim5_poder_prueba_promedio.csv`, `sim5_n_minimo.csv` |

## What changed in this commit
- The five notebooks are now saved **with their outputs** (the run of 27 Oct 2026). Code and text cells are identical to the previous versions; only the outputs were added.
- The CSV tables are added in `outputs/`.
- `requirements_vitaldb.txt` records the library versions printed in that run.

## How the CSV tables were obtained (please read)
The notebooks wrote these CSV files in the Colab session of 27 Oct 2026, but the files were not kept. Each CSV is exactly the table the notebook printed on screen (same rounding), so on 14 Nov 2026 the nine tables were rebuilt from the printed outputs saved inside the executed notebooks. They were not regenerated by a new run. Numbers, row counts and column names follow the notebook output. The small JSON parameter files that the notebooks also write (`sim3_parametros.json` and similar) were not printed and are not included.

## Known gaps
- The version of `statsmodels` was not recorded in the 27 Oct run. It is not pinned yet.
- Running the notebooks again in Colab will create native CSV and JSON files and record all versions; the numbers should match because the seeds are fixed (2026), up to differences between library versions.

## Reproducing
Open a notebook in Google Colab and choose Runtime, then Run all.
